v4.5.11 · Free & Open Source

Dodown is a desktop download manager that splits files into multiple concurrent connections to download faster and more reliably. Paste links, drop .torrent or .m3u8 files, or connect the built-in browser extension to automatically catch downloads from HTTP/HTTPS, BitTorrent, YouTube & media sites (yt-dlp), FTP, GitHub, HuggingFace, and arXiv.
